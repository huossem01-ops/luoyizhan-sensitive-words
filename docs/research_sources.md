# 历史调研来源（不作为当前候选数据源）

本页保留旧 10,000 条扩写实验的调研背景，供比较和审计。当前腾讯向量召回流水线不从这些网页抽取词条，也不再执行该扩写方案；当前实际数据源与许可证只以 `data_sources.md` 为准。

## 青春校园语义场

- [大陆校园青春片中“校园”元素分析（人民网）](https://media.people.com.cn/n1/2018/1018/c421787-30348942.html)：校园不仅是背景，也是管理青春期情感的空间机制；教室之外还包括小卖部、操场、天台、游泳池、练习房和自修室等关系表达空间。
- [青春题材电影中的空间叙事](https://www.fcpi.org/articleDetail/3434?periodicalId=6)：教室、走廊、操场等共性空间可以承载情绪，窗边位置、灯光等细节能把抽象情感转化为可感知符号。
- [这组国风毕业照，藏着我们的「青春诗篇」（中国大学生在线）](https://dxs.moe.gov.cn/zx/a/sy_lhxy/250611/2009017.shtml)：毕业季、蝉鸣、教室、图书馆、操场、风与发梢构成稳定的青春记忆节点。
- [女校生那些年的小秘密（文汇报）](https://dzb.whb.cn/html/2018-01/07/content_626596.html)：校服、课室、走廊、课外活动与传小纸条体现日常校园生活的物件和行为层。

## NLP 词库扩展方法

- [情感词典自动构建方法综述](https://www.aas.net.cn/cn/article/doi/10.16383/j.aas.2016.c150585?viewType=HTML)：总结知识库、语料库及混合方法，强调种子词、语义关系扩展和去噪。
- [基于语义规则的自适应情感词典自动构建算法](https://bhxb.buaa.edu.cn/bhzk/cn/article/doi/10.13700/j.bh.1001-5965.2023.0367)：采用固定高精度词典、领域新词发现、词性筛选和语义规则控制歧义。
- [A Corpus-Based Approach for Building Semantic Lexicons](https://arxiv.org/abs/cmp-lg/9706013)：从小规模类别种子出发，在代表性语料中排序候选，再由人工决定是否纳入。
- [LexExp](https://academic.oup.com/bioinformatics/article/37/16/2499/6007257)：以语义相似度产生候选，再用词面相似度阈值过滤，为“召回后去噪”流程提供参考。
