# 利用旧 Generated 数据发现遗漏概念

## 原则

旧 Generated 数据有一定借鉴意义，但用途限定为：

1. 发现原种子体系漏掉的语义类别；
2. 提供检索 seed 和人工审核维度；
3. 评估腾讯轻量词表对这些概念的覆盖情况。

旧词条不会直接复制进正式词库。每个新增候选必须来自腾讯真实词表，排除原 Top 5,000 后再经过腾讯向量召回、BGE 重排和明确审核。

## 发现的主要缺口

- 校园外貌与信物：刘海、马尾、发卡、发梢、酒窝、小皮筋、纽扣；
- 纸面心意与暗号：情书、小纸条、书签、信封、明信片、暗号；
- 校园空间与路线：走廊、图书馆、小卖部、广播站、看台、林荫道、公交站；
- 校园日常互动：留座、讲题、借笔记、递纸条、等车、合照；
- 青春感官与毕业：晚霞、晨光、铃声、雨伞、蝉鸣、毕业与离别；
- 约会物件与仪式：奶茶、玫瑰、电影院、摩天轮、电影票、纪念日。

## 腾讯轻量词表覆盖

腾讯轻量 vocabulary 能直接找到 `刘海、马尾、发卡、纸条、书签、走廊、图书馆、小卖部、晚霞、铃声、奶茶、玫瑰、雨伞` 等词。

`小皮筋、小纸条、借笔记、讲题、留座、毕业照、蝉鸣、情侣座` 在当前轻量词表中 OOV。它们可以作为 BGE 概念 seed 帮助排序，但自身不会被伪造进腾讯候选。例如 `小皮筋` 最终帮助发现并保留了真实词表近邻 `橡皮筋`。

## 运行结果

- 腾讯 vocabulary：143,613；
- 排除既有候选：5,000；
- 六类各召回最多 250 条；
- 跨类别去重后：1,445 条；
- 平衡审核样本：240 条；
- keep：150；
- borderline：44；
- reject：46；
- 最终扩展审核版：核心 160 + 新增 150 = 310 条。

新增词包括 `刘海、马尾、发卡、橡皮筋、纸条、书签、信封、明信片、走廊、图书馆、小卖部、广播站、林荫道、晚霞、晨光、铃声、雨伞、奶茶、玫瑰、摩天轮、电影票` 等。

扩展版平均长度 2.46，中位数 2，P90 为 4，最长 5；超过 12、16、30 字均为 0，规范化重复为 0。
