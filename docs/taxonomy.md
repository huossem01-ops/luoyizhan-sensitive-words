# 种子分类体系

当前类别用于组织种子和解释向量召回结果，不是封闭的人工标签本体。候选的 `best_category` 是与该类种子中心最相近的类别，仍需人工审核。

| 类别 | 代表概念 |
| --- | --- |
| 恋爱核心 | 恋爱、谈恋爱、恋情、爱情 |
| 对象关系 | 对象、男朋友、女朋友、伴侣、暧昧 |
| 校园恋爱 | 校园恋爱、早恋、同桌、校服、情书、小纸条、放学同行 |
| 表白与追求 | 表白、告白、暗恋、追求、被拒绝 |
| 约会 | 约会、约会邀请、看电影、散步、单独见面 |
| 亲密行为 | 牵手、拥抱、接吻、亲密关系、边界与同意 |
| 单身与脱单 | 单身、母胎单身、脱单、异性缘、没人喜欢 |
| 恋爱历史 | 初恋、前任、恋爱经历、失恋、分手 |
| 婚恋 | 结婚、婚姻、婚礼、相亲、催婚 |
| 社会比较与人生进度 | 同龄人、室友脱单、人生进度、青春遗憾、情人节 |

一个候选可能同时靠近多个类别。现阶段只记录最高类别中心，原始种子相似度可通过重新运行召回复现。类别分布若严重失衡，应先调整种子和抽样策略，而不是用句子扩写填充类别。
